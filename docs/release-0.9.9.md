# PaperRead 0.9.9

- 设置按钮只出现在左侧文献库中，折叠侧栏或专注阅读时一并隐藏，移除遗留的左下角悬浮入口。
- 返回文献管理使用文献库图标；左侧栏开关使用简单左右箭头。两者分别负责返回和展开/收起侧栏。
- 开关左侧栏保留当前 PDF 阅读点、解析滚动位置及右侧目录的显示状态。专注模式下只展开左侧栏时，不连带展开右侧目录。

- 设置窗口改为左侧分类与右侧内容，分为外观、阅读、模型、期刊标签、文献与数据、关于。保留原有选项与保存行为，分类切换支持键盘上下键。

- “文献与数据”显示临时缓存大小，可立即清理或设置每天、每周、每 30 天清理。默认关闭定时清理；软件未运行时不唤醒电脑，下次打开补做。只清理 HTTP 临时资源，不删除文献、MD、解析、笔记、登录、对话、后台任务和备份。
- 后台能耗提供自动节能和更省电。空闲任务检查由每 2.4 秒降为 30 秒或 120 秒，运行中任务仍及时更新，返回窗口立即刷新。系统传入 PDF 改为事件驱动接收，移除每秒空转检查。
- 打包时去重 Python 运行文件，排除开发工具、头文件、文档及字节码缓存；保留 MarkItDown、PDF 渲染、原图解析、OCR 和全部产品功能。
- 期刊分区表保留在使用者本机，公开源码和下载包不附带使用者提供的表格或个人文献数据。
